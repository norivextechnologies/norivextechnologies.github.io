APNI PHOTO BADALNE KE LIYE
==========================
1. Apni nayi photo ka naam "founder.png" rakho.
2. Is folder (my-photo) mein purani founder.png ko replace kar do.
3. Hostinger pe upload karke Purge cache kar do.

Best result: background hatayi hui (transparent) PNG, khade hue / half body, lambi photo (approx 600 x 900 px).
Normal JPG bhi chalegi: naam "founder.png" hi rakhna hai ya index.html mein "my-photo/founder.png" ko apni file ke naam se badal dena.
